# SAP S/4HANA Cloud Public Edition

Connect to your financial cloud system to retrieve information about organizational units, the factory calendar, and so on.

> ### Tip:  
> For SAP Advanced Financial Closing, a booster is available in the SAP BTP cockpit. This booster supports you with your initial setup of your **production tenant** by automating several of the setup steps.
> 
> For more information, see [Automated Setup for Production Tenant](../Automated-Setup/automated-setup-for-production-tenant-08b5486.md#loio08b54863254c43fda04b0726814e5506).

		your launchpad in SAP S/4HANA
