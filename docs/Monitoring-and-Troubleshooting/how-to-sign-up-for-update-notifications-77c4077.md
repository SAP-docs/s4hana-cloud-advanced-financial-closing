# How to Sign Up for Update Notifications

Receive email notifications about updates and system outages.



## Context

If you want to be informed about any system updates or outages, you can sign up to an email service in the [Cloud Availability Center](https://support.sap.com/en/my-support/systems-installations/cac.html).

This way, you'll receive information relevant for SAP Advanced Financial Closing.



## Procedure

Follow the steps described in one of the following documents to subscribe for notifications for SAP Advanced Financial Closing.

1.  SAP note [2900069](https://me.sap.com/notes/2900069)

2.  [Cloud Availability Center](https://support.sap.com/en/my-support/systems-installations/cac.html)




<a name="loio77c4077490714854a5e868afae6d2446__result_x3b_5k4_nsb"/>

## Results

You will now receive email notifications with information relevant for SAP Advanced Financial Closing.
